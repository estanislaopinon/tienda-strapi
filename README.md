# Tienda Strapi - E-Commerce Full Stack

Sistema e-commerce completo multiplataforma con backend Headless en Strapi v4 y aplicación móvil en React Native / Expo.

## 🚀 Módulos del Proyecto

- **[backend](./backend)**: API REST con Strapi v4, TypeScript, autenticación JWT, gestión de stock y base de datos SQLite.
- **[mobile](./mobile)**: Aplicación Móvil / Web desarrollada con Expo, Expo Router, TypeScript y manejo de estado con Context API.

## 🛠️ Inicio Rápido

### 1. Iniciar Backend
```bash
cd backend
npm run develop
```
Panel de administración en: `http://localhost:1337/admin`

### 2. Iniciar Aplicación Móvil
```bash
cd mobile
npm start
```
- Presiona **`w`** para abrir en navegador Web.
- Escanea el código QR con **Expo Go** en tu dispositivo móvil.
